# Evals and local tools

Commands for comparing prompt variants and checking speech. The evals (`evals/`) and the saved pages they read (`tests/fixtures/`) are kept locally and aren't in this repo, so these commands, `npm run speak` and `npm run lesson-stats` need them first.

- `npm run eval -- topup|level|speed|reading|passage|textbook|practice|mark|check|widget|hint|exercise|schedule|custom-lesson|match`: compare variants on fixture pages; dry run (requests, estimated cost) by default, `EVAL_RUN=1` calls the API with the key in `.anthropic_key` (gitignored, mode 600) and writes a Markdown report to `evals/out/` (plus JSON for topup and speed). No build needed. Options: `EVAL_PAGE(S)`, `EVAL_MODEL`, `EVAL_EFFORT`, `EVAL_VARIANTS`; reading also takes `EVAL_FORMATS`, `EVAL_LESSONS`; practice takes `EVAL_LESSONS` (default: the first lesson at each level in each language), `EVAL_EXERCISES` (per lesson, default 6), `EVAL_TYPES=all` (every exercise type the level has, or a list of type ids) and `EVAL_SEED`, and writes `evals/out/practice.md` (or `practice-all.md`) with every answer marked; level (the themed weave's top-up by the reader's level: `shipped` against one lesson request per paragraph with the A1 list as a check in code, `evals/variants/level.ts`) takes `EVAL_LANG` (default hi), `EVAL_LEVELS` (default A1,B1) and `EVAL_THINKING`, defaults to the extension's model settings, and picks the page words once per level; passage takes `EVAL_MODES`, `EVAL_FORMATS`, `EVAL_FOCUS`, `EVAL_LEVEL`, `EVAL_LESSONS`, `EVAL_RUNS`, `EVAL_SEED`, `EVAL_REBUILD_KITS=1` (kits are cached in `evals/kits/`); mark takes `EVAL_PAGES`, `EVAL_FOCUS`, `EVAL_LESSONS`; check (the mark check replayed on hand-labelled marks, `evals/mark/labels.json`, scored on bad kept and good dropped; Haiku variants and TypeSafe's Jev, key in `.typesafe_key`, gitignored, mode 600) takes `EVAL_RUNS`; widget (the widget's true-or-false keys, key facts and gaps judged against their section, on hand labels in `evals/widget/labels.json`; Jev and Haiku) takes `EVAL_RUNS`; hint (Jev's check on Practice hints, on hand labels in `evals/hint/labels.json`, scored on misleading and giving-away kept and good dropped at each threshold; Jev only, variants in `evals/variants/hint.ts`) takes `EVAL_RUNS`; exercise (Jev on a Practice exercise's key, claim by claim: each word of a tap exercise a use of the form or not, each gap option fitting or not, on hand labels in `evals/exercise/labels.json`, scored on broken exercises caught and good ones flagged at each threshold; variants in `evals/variants/exercise.ts`) takes `EVAL_RUNS`. The passage eval also writes its page-mode pieces as JSON and counts broken ones (`evals/widget/checks.ts`); custom-lesson (lessons the reader writes, `src/syllabus/custom.ts`: five sample requests, short and long, one with a wrong form and one above its level, each written by every variant in `evals/variants/custom-lesson.ts`, judged by hand) takes `EVAL_REQUESTS` (indexes from 0); schedule makes no API calls: it simulates long Practice sessions on the cached kits, the shipped picker against `src/practice/schedule.ts` (points, types, stages, words, missed points, a returning reader), and writes `evals/out/schedule.md`; takes `EVAL_SESSIONS`, `EVAL_LENGTH`, `EVAL_SEED`; match (prototypes for more flexible lesson matching, timed on the fixture pages, the ones that need the model sent as variants; nothing in the extension uses them yet) takes `EVAL_PAGES`, `EVAL_MODEL`, `EVAL_EFFORT`, `EVAL_VARIANTS` (idea numbers) and `EVAL_SAMPLE` (paragraphs per page sent)
- `npm run speak`: a local page (http://localhost:5178) to record yourself saying sentences in each language (`evals/speak/sentences.json`, each said right or with a deliberate mistake) and send the clips to speech recognisers (Whisper large-v3 and turbo on DeepInfra, with and without the expected sentence as a prompt; Google Speech-to-Text v1, `.google_stt_key` or `.google_tts_key`). Nothing is sent until you press Check; clips and results in `evals/speak/`, report in `evals/out/speak.md`. Picked: `whisper-v3-prompted`, now in `src/listen.ts`
- `npm run lesson-stats`: density a lesson reaches on `tests/fixtures/` pages, with no API calls
