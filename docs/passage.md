# The passage

The widget's passage, the lesson kit and the Lesson tab.

- `src/passage/`: the widget's passage. `formats` (27 formats from the ESL review, each with instructions for a page and for a lesson scene; quiz formats add a third field to some lines), `piece` (choices, prompt, parser, one Sonnet call with thinking off, streamed), `checks` (checks in code on every piece: broken lines dropped, a piece still broken (too few quiz lines, readings left off more than a fifth of the words in a script that takes them) written once more; `LanguageConfig.functionWords` tells a target-language line from English), `verify` (page mode with a TypeSafe key: Jev checks true-or-false keys, gaps and fact lines against the section as they stream in, and drops what fails), `kit` (lesson mode, once per lesson: theme, words, scene settings, points, pitfalls; Sonnet, structured output, cached in `chrome.storage.local`), `context` (page sections; page mode is about the section on screen, after the lead's first lines), `controller` (the widget: page mode writes each section as a simple summary, its format chip a menu to write it in another; lesson mode a random format per piece, avoiding the last few; "New passage" writes the same section or scene in a random other; page mode writes again when scrolling (the page or a box on it) settles on another section, or the page shows new text there (`refocus`), one request at a time, each section kept by its heading and first words; text highlighted in the article (6 words or more) is written about instead, as one more section under the heading of the one it's in (`withSelection`), and stays until a scroll with nothing highlighted; lesson mode has a Lesson tab), `textbook` (the Lesson tab: the lesson's grammar and vocabulary as a textbook page, from the lesson alone; once per lesson, Sonnet, structured output, cached in `chrome.storage.local`). `npm run eval -- passage` writes `evals/out/passage.md` (every format in both modes); variants in `evals/variants/passage.ts`; `npm run eval -- textbook` writes `evals/out/textbook.md`, variants in `evals/variants/textbook.ts`
