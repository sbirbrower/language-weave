# The weave

The pipeline that weaves words into the page, and the lessons and word lists it draws on.

- `src/weave/`: pure pipeline modules: `segment` → `prompt` → `parse` → `select` (locate + validate + budget) → `write`
- The reader's level (`Settings.level`) goes in the user message of each general request, the general weave and a lesson's free top-up (`levelNote` in `src/weave/prompt.ts`); the system prompt names no level, so it stays the same for every reader. The page-word picker gets the level the same way. Up to A2 a weave lesson keeps its beginner lists (easy words, the A1 top-up); from B1 `forLevel` (`src/lessons/level.ts`) drops them, and `aboveBeginner` turns away a general request's lemmas that are on the A1 list (the model returns some about one time in seven).
- Where the text is (`findPageText` in `segment`): the paragraph tags of `main`/`article`, else of the body; a page with none (a video page, built from spans and custom elements) is read loosely, by each text's nearest element laid out as a block, blocks under 6 words dropped
- Text that comes later (more loaded as the reader goes, a reader's pages turned, a block drawn again): `content.ts` watches the page (`watchText`, at most once a second, not for its own writes), drops segments the page took away (`isGone`), and plans and weaves the new ones with the same settings and page words; the page-mode passage follows (`refocus`). Page words are picked once, from the text there at the start
- Frames: the background probes every frame and runs in the top page unless it's a shell under 100 words around a frame with more text, like Google Play Books' reader (`src/frames.ts`)
- `src/weave/plan.ts`: decides every segment's lesson words, page words and model requests before anything is sent (`carry.ts` moves shortfalls to paragraphs sent later); `src/cost.ts` prices them (hardcoded price table, calibrated from real usage)
- `src/lessons/`: lesson interface, word-bank engine (`bank.ts`), page-level `allocate`, `resolve` (code-written vs model lines); one folder per lesson (`basics/`); `pageWords.ts`: a vocabulary picked per page from its headings and what's on screen, then spread across the page alongside any lesson; `easy.ts`: the easiest English words with an obvious French, found by code and spent (easiest first) once a lesson's own words run out; `extras.ts` combines a lesson with both, the same way in the plan, content script and background
