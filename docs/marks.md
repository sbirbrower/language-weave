# Marks

Lesson mode's marks on the page.

- `src/marks/`: lesson mode's marks on the page (popup "Mark this page", that page only): where the English on screen can practise the lesson, glossed with the target language after it, never the lesson fitted to the page. `prompt` (Sonnet, thinking off, the sweep: about twice the marks, for the check to cut; methods, parser, `placeMarks`), `jev` (TypeSafe's Jev, the first check on each mark when Options has a TypeSafe key: drops below 0.2, keeps from 0.6, ~0.15s), `check` (the model check per mark: a lenient Sonnet for what Jev isn't sure of; Haiku for every mark without a TypeSafe key), `stream` (`markSection`: the marking call, each mark checked and shown as its check passes), `write` (Ranges: the English wrapped, the gloss after it, skipped as page text; `removeMarks`), `popup` (a click on a mark: target, English, the point, a play button), `card` (while marked: how many marks the page has and for which lesson, with "Weave instead" and "Clear"; the minimised widget shows the count too), the marks drawn as a dotted green underline with the gloss in green italics after it, `controller` (the chunk on screen, `sectionChunks`, one request at a time as the reader scrolls). `npm run eval -- mark` writes `evals/out/mark*.md` and `.html` (each section with the marks drawn, switchable between gloss, weave and highlight; `evals/mark/report.ts`); variants in `evals/variants/mark.ts` (`sweep-cascade-sonnet` is what ships with a TypeSafe key, `gloss-sonnet-check2` without one; `evals/mark/labels-shown.json` labels round 7's shown marks)
